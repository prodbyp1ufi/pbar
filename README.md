# Bar — морфинг-пилюля для Hyprland

Полностью функциональный бар для [Quickshell](https://quickshell.outfoxxed.me) в стиле
динамического «острова»: в свернутом виде это компактная пилюля с модулями, по клику
она плавно (BezierSpline-морф) растягивается в панель-поверхность — календарь,
микшер, Wi-Fi и т.д. Лаунчер и история буфера — не морф: это центрированные
карточки-спотлайты (как macOS Spotlight) поверх того же overlay-окна.
Вдохновлен [ukishima](https://github.com/amanhex/ukishima).

## Возможности

- **Пилюля-бар** (свернутая): раскладка, время с датой по центру и action-слот —
  идёт запись экрана → красный индикатор записи (важнее всего остального),
  играет музыка → эквалайзер, фокус в приложении → его иконка, иначе процент
  батареи (зарядка — зелёный, <25% — красный). **Левый клик** — Control Center,
  **правый клик** — центр уведомлений
- **Поверхности** (клик по модулю → морф в панель):
  - Календарь (русские названия месяцев/дней)
  - Медиа: обложка, перемотка, управление плеером (MPRIS)
  - Снимок экрана / Запись экрана, Обои
  - Ресурсы: CPU, память, диск, сеть, температура
  - Питание: выход / блокировка / сон / перезагрузка / выключение (с подтверждением)
  - Центр уведомлений: DND, история по приложениям, очистка
  - Микшер, Wi-Fi, Bluetooth, Батарея — остались как отдельные поверхности для IPC-биндов;
    в основном UI их заменил Control Center (см. ниже)
- **Спотлайт** — центрированная карточка посреди экрана (чуть выше середины),
  fade + scale при появлении, закрытие по Esc/клику мимо. Пилюля при этом
  остается свернутым баром:
  - **Лаунчер приложений** (`bar launcher`): поиск по DesktopEntries, стрелки +
    Enter с клавиатуры, клик мышью. Если по запросу приложений нет — три действия:
    искать запрос в Google (xdg-open, браузер по умолчанию), открыть путь
    в файловом менеджере (superfile в kitty; если путь не существует — домашняя
    папка), выполнить запрос в терминале (`kitty --hold` — окно не закрывается
    после выполнения)
  - **История буфера** (`bar clip`): поиск по текстовым записям (подстрока,
    без регистра), Enter/клик — вернуть запись в буфер, Backspace при пустой
    строке поиска — удалить выбранную запись, Delete — очистить всю историю,
    картинки показываются только когда поиск пуст
- **Тосты**: уведомление показывается прямо в пилюле — пилюля морфится
  в карточку (иконка, приложение, задоловка, текст, бейдж «+N» для остальных),
  со звуком (pw-play + звуки freedesktop). Свой NotificationServer —
  dunst/mako не нужны и будут конфликтовать. Локальные уведомления бара:
  разряд батареи — «низкий заряд» приходит на пороге авто-экономии
  (если она включена; иначе на 20%), «критический» — на 10%. Приложения,
  играющие свой звук, определяются автоматически: перед нашим звуком бар
  ищет активный аудиострим приложения в PipeWire (`pactl`) и не дублирует
  его; критические и локальные уведомления звучат сразу.
  Клик по тосту вызывает default-действие и поднимает окно приложения
- **OSD в пилюле**: громкость, микрофон, яркость (в т.ч. по хоткеям) и
  подключение зарядки рисуются внутри пилюли (тонкая полоска + %),
  мгновенно — события PipeWire через pactl subscribe
- Ввод маршрутизируется маской окна: пустые места кликаются насквозь, клик мимо
  открытой поверхности закрывает её, Esc тоже
- В фулскрине бар прячется и освобождает зарезервированную полосу
- Мульти-монитор: пилюля на каждом экране, тосты и OSD — только на фокусном
- Звук слайдеров обновляется мгновенно из любых источников (хоткеи, приложения)
  — подписка на события PipeWire (`pactl subscribe`)

## Зависимости

- `quickshell` ≥ 0.3 (проверено на 0.3.1) + Hyprland (`hyprctl`)
- `networkmanager` (`nmcli`) — Wi-Fi
- `bluez` (`bluetoothctl`) — Bluetooth
- `power-profiles-daemon` (`powerprofilesctl`) — профили питания
- `brightnessctl` — яркость; `wireplumber` (`wpctl`) — звук; `pw-play` +
  звуки freedesktop (`sound-theme-freedesktop`) — звук уведомлений
- `grim` + `slurp` + `gpu-screen-recorder` — снимки и запись экрана
- `jq` — разбор ответов `hyprctl -j` (выбор окна для снимка/записи, клик по тосту)
- `wl-clipboard` + `cliphist` — буфер обмена (в т.ч. картинки)
- `qrencode` — QR-код пароля Wi-Fi («поделиться» сетью)
- `awww` (форк `swww`) — обои
- `kitty` + `superfile` (`spf`) — открытие папок
- Желательно любой MPRIS-плеер для медиа-модуля
- Шрифт `JetBrainsMono Nerd Font` (палитра в `Singletons/Theme.qml` меняется на любой)

## Запуск

```sh
qs -p ~/Projects/Bar
```

Точка входа — `shell.qml` в корне папки.

### Автозапуск

В `~/.config/hypr/hyprland.conf`:

```ini
exec-once = env QSG_RHI_BACKEND=vulkan MALLOC_ARENA_MAX=2 qs -p ~/Projects/Bar
```

Обе переменные важны, они снижают потребление памяти примерно на 130 МБ:

- `QSG_RHI_BACKEND=vulkan` — без неё Qt может откатиться в программный рендеринг
  (llvmpipe): +70 МБ RSS и лишняя нагрузка на CPU. Проверить, что GPU-рендеринг
  работает: `cat /proc/<pid>/maps | grep -c vulkan` — должно быть не 0.
- `MALLOC_ARENA_MAX=2` — glibc по умолчанию плодит malloc-арену на каждый поток,
  это ~60 МБ лишней приватной памяти у Qt-приложений.

Итоговые замеры этого бара: ~370 МБ RSS на дефолтном запуске → ~230 МБ с обеими
переменными (из них ~127 МБ — разделяемые библиотеки Qt/Mesa/LLVM, которые есть у
любого GUI-приложения; приватная память — ~77 МБ).

> Если запущен ukishima или другой quickshell-бар — остановите его: два notification
> daemon'а и два бара на одной полосе экрана работать не будут. Остановить ukishima:
> `kill (pid of quickshell)` или `qs --all list`, затем `qs kill <...>`.
>
> В `hyprland.lua` (Hyprlua-конфиг) строка автозапуска выглядит так:
>
> ```lua
> hl.exec_cmd("env QSG_RHI_BACKEND=vulkan MALLOC_ARENA_MAX=2 qs -d -p /home/p1ufi/Projects/Bar")
> ```

### Отключить другие notification daemon'ы

Бар сам является NotificationServer. Уберите из автозапуска `dunst`, `mako`,
`swaync` и т.п., иначе тосты будут дублироваться или пропадать.

## Control Center (хаб)

Пилюля в свернутом виде — левый клик открывает Control Center: единая панель, все
настройки инлайн (отдельных окон для сетей/Bluetooth/звука больше нет). Высота
подстраивается под содержимое (максимум 680), фон при открытой поверхности —
непрозрачная карточка (стекло только у свернутой пилюли):

- **Системный трей** — первая строка; wifi-апплет из трея отфильтрован (сети живут
  ниже), при пустом трее строка скрывается
- **Сетка 2×2 + мониторинг** — Wi-Fi, Bluetooth / «Не беспокоить», батарея:
  только иконки в кружках, без подписей. Тап включает/выключает; **ПКМ** по Wi-Fi /
  Bluetooth открывает контекстное меню: сети Wi-Fi с вводом пароля и «забыть»,
  устройства Bluetooth с автопоиском, подключением/отключением/«забыть»
- **Вертикальные слайдеры (50 px)** — под плитками: яркость, звук, микрофон:
  заливка снизу, как в iOS; тап по позиции, непрерывный драг и колесо мыши
  (до 100% долистывается, прокрутка хаба под курсором блокируется); изменения
  через хоткеи подхватываются опросом (~0,6 с, пока хаб открыт); **ПКМ** по
  звуку/микрофону — меню устройств вывода/входа (в шапке — mute)
- **Мониторинг** — высокая карточка справа (на всю высоту блока): CPU (с
  температурой), ОЗУ и диск (использовано / всего + тонкая полоска загрузки с
  пороговыми цветами), сеть (↓ приём / ↑ отдача); полная поверхность «Ресурсы»
  доступна через IPC: `qs -p ~/Projects/Bar ipc call bar res ""`
- **Плеер** — появляется, только когда что-то играет: перемотка по шкале
  (текущее время / длительность), prev / play-pause / next, перемешивание
  и повтор (выкл → трек → очередь — если плеер умеет)
- **Кнопки быстрого доступа** (прямоугольные) — снимок/запись, обои, тема,
  питание; клик морфит пилюлю в соответствующую поверхность: скриншот и запись
  (область / окно / экран, при записи — таймер и красный «стоп»), обои
  (выбор / папка / случайная), настройка темы (фон / текст / акцент с пресетами),
  питание (блокировка, выход, сон; ребут/выключение — с подтверждением «Точно?»).
  История буфера — только по IPC-бинду `bar clip` (спотлайт-карточка)
- **Батарея (сетка 2×2)** — клик открывает контекстное меню: в шапке — процент
  (иконка с заливкой и молнией при зарядке), при зарядке — строка «Заряжается ·
  время до полной»; профиль — круглые иконки (макс / баланс / эконом); слайдер
  «Авто-экономия» с делениями каждые 10% — порог заряда, ниже которого профиль
  сам переключается на энергосбережение, при зарядке прежний профиль
  возвращается (0 = выкл; порог хранится в ~/.cache/bar/battery.json)

Клавиатура в хабе не перехватывается, пока она не нужна: поле пароля Wi-Fi при фокусе
само запрашивает Exclusive-режим (вне хаба поверхности получают клавиатуру сразу).

## Управление из биндов Hyprland (IPC)

Все поверхности открываются через IPC, пустой аргумент монитора = фокусный:

```ini
bind = $mainMod, SPACE, exec, qs -p ~/Projects/Bar ipc call bar launcher ""
bind = $mainMod, C, exec, qs -p ~/Projects/Bar ipc call bar calendar ""
bind = $mainMod, V, exec, qs -p ~/Projects/Bar ipc call bar mixer ""
bind = $mainMod, W, exec, qs -p ~/Projects/Bar ipc call bar wifi ""
bind = $mainMod, M, exec, qs -p ~/Projects/Bar ipc call bar media ""
bind = $mainMod, B, exec, qs -p ~/Projects/Bar ipc call bar battery ""
bind = $mainMod, N, exec, qs -p ~/Projects/Bar ipc call bar notifs ""
bind = , XF86AudioMute, exec, qs -p ~/Projects/Bar ipc call bar sinkmute ""
bind = , XF86AudioMicMute, exec, qs -p ~/Projects/Bar ipc call bar micmute ""
bind = $mainMod, ESC, exec, qs -p ~/Projects/Bar ipc call bar power ""
bind = $mainMod, Q, exec, qs -p ~/Projects/Bar ipc call bar close
```

Повторный вызов той же поверхности закрывает её. `close` вызывается без аргументов.

## Настройка

- Цвета/шрифт — `Singletons/Theme.qml` или на лету из поверхности «tint»
- Персистентные данные — `~/.cache/bar/`: `theme.json` (тема) и `battery.json`
  (порог авто-экономии); старые `~/.cache/bar-*.json` переезжают туда сами
  при первом старте
- Длительность и кривая морфа — `Singletons/Motion.qml`
- Высота резервируемой полосы — `bandH` в `shell.qml` (по умолчанию 56 px × масштаб)
- Отступ пилюли от верха — `y: 8 * overlay.s` в `shell.qml`
- Масштаб интерфейса вычисляется как `высота_экрана / 1080`
